HƯỚNG DẪN CÀI ĐẶT BỘ FINAL V15.1
=================================

PHIÊN BẢN EDGE FUNCTION:
KEY_API_HARDENED_V15_1_GTRAFFIC_FIX_20260804

I. CÁC CHỨC NĂNG ĐÃ GOM TRONG BỘ NÀY
-------------------------------------
1. Không cấp key khi người dùng vào thẳng key.html hoặc tự tạo URL /k/...
2. Session chỉ được cho phép claim sau khi API tạo đủ link rút gọn.
3. Bắt buộc tối thiểu 30 giây theo đồng hồ server, tính từ lúc bấm Lấy Key
   và backend bắt đầu tạo session/link.
4. Dưới 30 giây: không lấy key khỏi kho và báo:
   "Key Lỗi .. Vui Lòng Vượt Lại".
5. Key, session, UID/landing code chỉ sử dụng một lần.
6. Sau khi key hiện, reload/đóng tab/mở lại URL sẽ không hiện lại key.
7. Không lưu key vào localStorage, sessionStorage, cookie hoặc URL.
8. Ràng buộc IP, device ID, journey secret, User-Agent và Turnstile.
9. Claim key nguyên tử trong SQL, chống hai request đồng thời.
10. Admin cấu hình GTraffic:
    https://gtraffic.io/st?apikey=API_KEY&url=
11. API key GTraffic nhập riêng trong Admin, không đặt trong config.js.
12. Chọn 1-6 lần rút gọn lồng nhau.
13. Nếu bất kỳ lớp rút gọn nào lỗi, session bị xóa và không cấp key.
14. Bản vá V15.1 nhận thêm:
    - HTTP 301/302 + header Location
    - URL dạng text
    - URL tương đối
    - Một số dạng JSON khác nhau
15. Giao diện nền trắng kiểu GTraffic, ô Key màu vàng kem.
16. Phần "Chưa Kết Nối" không có nền hồng, không có viền.
17. Có hiệu ứng hoa anh đào rơi nhẹ phía sau nội dung.

II. THỨ TỰ CẬP NHẬT BẮT BUỘC
-----------------------------
BƯỚC 1 - SUPABASE SQL EDITOR
- Mở Supabase > SQL Editor.
- Chạy TOÀN BỘ file claim_limits.sql.
- Nếu đã chạy đúng file V14_30S trước đó thì không bắt buộc chạy lại,
  nhưng chạy lại toàn bộ file này vẫn giúp đồng bộ function/policy.

BƯỚC 2 - SUPABASE EDGE FUNCTION
- Mở Edge Functions > key-api.
- Thay toàn bộ code bằng index.ts.
- Deploy lại function.

BƯỚC 3 - SUPABASE EDGE FUNCTION SECRETS
Giữ/đặt đầy đủ:
- SUPABASE_URL
- SUPABASE_SERVICE_ROLE_KEY
- KEY_PAGE_URL=https://TEN-MIEN-CUA-BAN/key.html
- ADMIN_PASSWORD=mật khẩu admin tối thiểu 8 ký tự
- ADMIN_EMAIL=email admin
- ADMIN_TOKEN_SECRET=chuỗi ngẫu nhiên tối thiểu 32 ký tự
- CLAIM_TICKET_SECRET=chuỗi ngẫu nhiên tối thiểu 32 ký tự, khác token admin
- ALLOWED_ORIGIN=https://TEN-MIEN-CUA-BAN
- TURNSTILE_SECRET_KEY=secret Turnstile
- TURNSTILE_REQUIRE=true
- TURNSTILE_EXPECTED_HOSTNAME=TEN-MIEN-CUA-BAN
- ADMIN_BIND_IP=true
- MIN_JOURNEY_SECONDS=30

Không đặt service_role hoặc secret GTraffic trong frontend.

BƯỚC 4 - CONFIG.JS
Kiểm tra:
- SUPABASE_URL
- SUPABASE_PUBLISHABLE_KEY (anon/publishable, không phải service_role)
- TURNSTILE_SITE_KEY
- ADMIN_EMAIL

BƯỚC 5 - VERCEL/HOSTING
Upload/thay đầy đủ:
- index.html
- key.html
- admin.html
- config.js
- vercel.json

Sau đó Deploy lại và hard refresh bằng Ctrl + F5.

III. CẤU HÌNH GTRAFFIC TRONG ADMIN
----------------------------------
- Tên API: GTraffic
- Link API:
  https://gtraffic.io/st?apikey=API_KEY&url=
- API Key: chỉ dán token GTraffic vào ô API Key
- Bật: Có
- Số lần rút gọn: thử 1 lần trước, sau đó tăng lên 2-6 nếu cần
- Bấm "Lưu Cấu Hình Rút Gọn"

Không dán API key vào config.js hoặc HTML.

V. KIỂM TRA NHANH
-----------------
1. Vào thẳng key.html:
   - Không hiện key.
2. Tự nhập URL /k/mã-bất-kỳ:
   - Không hiện key.
3. Tạo link và đến trang đích dưới 30 giây:
   - Báo "Key Lỗi .. Vui Lòng Vượt Lại".
4. Claim thành công rồi reload:
   - Không hiện lại key; URL hết hiệu lực.
5. Dùng cùng URL trên trình duyệt khác:
   - Bị chặn bởi device/journey proof.
6. Chọn 2 lần rút gọn:
   - Kết quả lần 1 phải được dùng làm URL đích của lần 2.
7. GTraffic lỗi:
   - Web báo lỗi lớp rút gọn và session không được cấp key.
